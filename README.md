## 🚀 Installation & Local Setup

```bash
# Clone the repo
git clone https://github.com/bello-damy/portfolio
cd portfolio

# Install dependencies
npm install

# Run the development server
npm run dev
```

To build for production:

```bash
npm run build
npm run start
```
